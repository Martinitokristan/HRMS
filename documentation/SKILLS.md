## **🏗️ ARCHITECTURAL SKILLS**

### **📐 System Architecture**
- **Microservices Architecture**: Understanding of service decomposition, inter-service communication, API gateway patterns
- **Monolithic Architecture**: Modular design, dependency management, scalability considerations
- **Event-Driven Architecture**: Event sourcing, CQRS, message queues
- **Domain-Driven Design**: Bounded contexts, aggregates, domain events
- **Clean Architecture**: Layer separation, dependency inversion, use cases

### **🔌 API Design**
- **RESTful API**: Resource modeling, HTTP methods, status codes, versioning
- **GraphQL**: Schema design, resolvers, subscriptions
- **API Documentation**: OpenAPI/Swagger, Postman collections
- **API Security**: Authentication, authorization, rate limiting, input validation
- **API Testing**: Unit tests, integration tests, contract testing

### **🗄️ Database Architecture**
- **Database Design**: Normalization, denormalization, indexing strategies
- **Data Migration**: Version control, rollback strategies, zero-downtime deployments
- **Database Scaling**: Read replicas, sharding, partitioning
- **Data Integrity**: Constraints, transactions, consistency models
- **Performance Tuning**: Query optimization, indexing, caching strategies
