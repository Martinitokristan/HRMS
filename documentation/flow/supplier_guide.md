# Supplier Operations Flow

Suppliers act as external partners with their own dedicated workspace.

## 1. Catalog & Category Organization
- **Sidebar Dropdown (Category Module)**: The Supplier dashboard features a dedicated "Category" module in the sidebar. 
- **Dynamic Dropdown**: Clicking this module reveals a dropdown of categories relevant to the supplier's inventory.
- **Organized Entry**: When a supplier adds a product, it is automatically organized based on its assigned category.
- **Search & Filter**: Suppliers can quickly locate their products via the category hierarchy.

## 2. Request Notifications & Approval
- **Notifications**: Suppliers are instantly notified when an Admin makes a stock request from the "Specific Module".
- **Decision**:
    - **Approve (Accept)**: Approving the request triggers an **automatic inventory update** on the Admin side.
    - **Decline (Reject)**: Provide a reason if the request cannot be fulfilled.

## 3. Data Integration
- Suppliers do **not** affect "Store Stock" directly. They only supply the "Warehouse", which the Admin then distributes.
